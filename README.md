# haventinnn

A tiny command-line utility that prints a greeting and today's date in UTC.

## Run

Requires Node.js 18 or newer. No dependencies to install.

```bash
npm start
npm start -- Ada
node src/index.js ENTINNN
```

Example:

```text
Hello, Ada! Today is Thursday, November 5, 2026.
```

## Test

```bash
npm test
```
